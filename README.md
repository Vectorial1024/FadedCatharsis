# FadedCatharsis
A RimWorld mod: Catharsis Thought is now much weaker.

Reimagine the forgotten legacy of v0.xx alpha-stage RimWorld by significantly nerfing Catharsis to provide only +5 mood, down from the modern-day +40 mood. (Early RimWorld versions simply do not have the Catharsis mechanics.)

(Void Catharsis from the Anomaly DLC is unchanged for DLC-lore reasons.)

Package ID: "V1024.FadedCatharsis"

# Non-Steam Downloads
You can manually download the contents of this repository as a zip-file, and unzip it in your `/Mods` directory for installation.

Alternatively, the tech-savvy may also consider using `git clone` instead.
